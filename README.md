# 덤프트럭 차량리스트 자동 정리

업체가 제출한 폴더·ZIP·PDF·사진·엑셀을 넣으면 차량번호별로
업체 / 등록증 / 검사 만료 / 보험 만료 / 교육 만료를 정리해 엑셀로 내려받는 웹페이지입니다.

- 주소: https://leejinseok9612.github.io/dump-truck-list/
- 판독: Google Gemini API (키는 저장소에 없음 — 관리자 화면에서 접속 코드로 암호화한 공유 링크에만 들어감)
- 결과는 각 PC 브라우저에만 임시 저장

## 처음 설정 (관리자)
1. 페이지 맨 아래 `관리자 설정` 클릭
2. Gemini API 키 입력 → `모델 목록 불러오기` → `키 테스트`
3. 접속 코드 정하고 `공유 링크 만들기`
4. 다른 PC에는 공유 링크와 접속 코드를 따로 전달

## 쓰는 법
1. 공유 링크로 열고 접속 코드 입력 (이 PC에서 기억 가능)
2. 폴더나 ZIP을 끌어다 놓고 `분석 시작`
3. 표에서 확인·수정 후 `엑셀 다운로드`
